# 🍽️ FoodOrbit

AI-Powered Restaurant SaaS Platform

---

## Overview

FoodOrbit is a modern SaaS platform that helps restaurants automate daily operations using Artificial Intelligence.

Restaurants can manage:

- Orders
- Menu
- Customers
- Reservations
- Analytics
- AI Assistant
